# Security policy

## Reporting a vulnerability in Session Afterlife

Please do not open a public issue. Use GitHub's **Report a vulnerability** button in the **Security** tab of this repository, which opens a private advisory.

Include what an attacker can do, the steps to reproduce, and the version of the extension. You will get an answer within a week.

Examples of what counts: the extension leaking session values outside the browser, replaying requests to sites outside the scope list, replaying state-changing requests, or a web page being able to read or influence the extension's data.

## Vulnerabilities in other applications

Session Afterlife is a testing tool. Findings it reports about applications you test belong to those applications' owners. Report them through their own disclosure process, and only test applications you are authorized to test.
